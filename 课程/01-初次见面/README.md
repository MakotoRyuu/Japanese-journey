# 第 01 课 · 初次见面

每个文件是一份可独立复习的小节讲义。按顺序学习，每节约 3–5 分钟。

1. [用一句话介绍自己](01-用一句话介绍自己.md)：A は B です；助词は的读音。
2. [僕、私与姓名的称呼](02-僕和私以及姓名的称呼.md)：自称、誠的读法与さん。
3. [三句完整的自我介绍](03-三句完整的自我介绍.md)：初次见面的完整表达。
4. [用ですか提问](04-用ですか提问.md)：询问身份与肯定回答。

5. [怎样回答不是](05-怎样回答不是.md)：否定身份与补充说明。

[练习答案](练习答案.md)单独保存，做完题再看。

## 怎么复习

先看每节末尾的“记忆卡”，再遮住例句做练习。答不出的地方回看对应段落。
次日复习自我介绍，约三天后再练疑问句；这些是建议间隔，未设置自动提醒。

## 本课完成标准

能独立介绍自己，知道は在句中读わ，能正确使用さん，并能使用ですか提问。书面、口头与听辨能力分别确认。
