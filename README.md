## 每次怎样学习

1. 打开一个小节，先看学习目标，再读讲解和例句。
2. 把例句读出声，替换姓名或身份，试着表达自己的意思。
3. 遮住例句完成练习，再查看单独保存的答案。
4. 把答案或疑问发到学习对话中，经过反馈后再复习薄弱点。
5. 下次学习前，用几分钟回忆上一节；能独立说出、写出后再继续。

每天可以先安排 15–20 分钟，按自己的节奏调整。“读过讲义”和“能够使用”分开记录，书面练习也不代替听说练习。

## 后续学习方向

第一课之后，计划逐步学习物品与归属、数字与时间、日常活动、地点与移动、喜好与描述、人物和物品的位置，以及简单的过去表达。具体顺序根据练习反馈调整，尚未编写的内容不列为已完成课程。
