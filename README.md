## 版本管理

在仓库根目录执行：

```sh
# 查看新增和修改的文件
git status

# 添加确认需要保存的文件
git add README.md .gitignore .gitattributes .editorconfig
# 添加讲义时，将路径替换为实际文件或文件夹名称
# git add "课程名称/"

# 保存一次版本
git commit -m "整理讲义资料"
```

提交前可用 `git diff --cached --stat` 检查暂存的文件清单。

## 仓库配置

- `.gitignore`：忽略系统杂项、编辑器缓存、Office 临时文件和本地环境配置。
- `.gitattributes`：统一文本文件的换行符，将常见讲义与媒体格式标记为二进制文件。
- `.editorconfig`：为支持此配置的编辑器提供统一的文本格式。

PDF、Word、PowerPoint、Excel、图片及音视频文件默认可以提交。大型媒体文件较多时，可再配置 Git LFS。
